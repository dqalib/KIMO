# KIMO — Project Brief

Repo: https://github.com/dqalib/KIMO

Kumon-style daily practice web app for **DQ's own children**, **Years 1–4 (ages 5–9)**. Private family use — no payments, no public sign-up.

## Users (school year 2026/27)
| Child | Year | Key focus |
|---|---|---|
| Yaqub Qalib | Year 4 | Times tables to 12×12 — Multiplication Tables Check, June 2027 |
| Yonis Qalib | Year 3 | Times tables (3s, 4s, 8s), column methods, spelling |
| Shirwa Qalib | Year 1 | Phonics — Phonics Screening Check, June 2027; number bonds |

Each child starts from a placement test, so levels may sit above or below their school year.

## Scope
- **Subjects:** Maths and English (phonics, spelling, grammar, reading comprehension). No handwriting at launch.
- **Method:** placement test → small graded levels → mastery gates (accuracy + time target) → daily 10–20 min practice, streaks, corrections.
- **Curriculum:** UK National Curriculum. Hooks: Y1 Phonics Screening Check, Y4 Multiplication Tables Check.
- **Content rule:** own content only — never copy Kumon worksheets, level names or branding.

## Structure
1. **Child area** — pick your profile (avatar + simple PIN), do today's practice. Tablet-first, big buttons, number pad, audio for phonics.
2. **Parent dashboard** — progress per child, time spent, levels passed/stuck, set daily goals, reset/skip levels.
3. **Content review** — approve / edit / reject AI-drafted English passages before the kids see them.

No marketing site, no payments, no public registration.

## Stack
- Next.js (App Router), hosted on Vercel (free tier)
- Supabase (free tier) — Postgres, one parent login, child profiles
- PWA — installable on tablets/phones
- Maths questions generated by code; English passages AI-drafted, parent-reviewed

## Privacy (family use)
- One parent account; children have profiles only (first name/nickname + avatar), no emails.
- Store only what's needed: answers, scores, times.
- No ads, no tracking, no third-party analytics.
